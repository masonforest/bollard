Bollard

A cross-chain exchange where balances are bonded promises, finalized on Bitcoin.

Makers stake BLRD and issue options on coins they hold; one stake backs everything a maker issues. Holders send, receive and trade those options instantly and for free, in whatever currency they choose, and exercise them to take the real coin out. If a maker fails to deliver, a share of its stake goes to the holder, and anyone may deliver in its place. Nothing is wrapped and nobody holds custody.

One leader at a time sequences everything in milliseconds. Bitcoin picks the leader: every block runs a fee-weighted lottery over entries written to Bitcoin itself, and each winning entry commits to the log, which is how the log is finalized.

AppA wallet: create a passkey, deposit, send in any currency, withdraw. Pro mode has the book and charts. White paperThe protocol in full: lottery, sequencing, options, stake. SourceThe node, in Rust. One binary and a Postgres database. APImainnet.bollard.exchange: JSON and server-sent events.

Run a node

cargo install --git https://github.com/masonforest/bollard
bollard keygen
DATABASE_URL=postgres://localhost/bollard BOLLARD_KEY=<secret> \
GENESIS_HEIGHT=971258 GENESIS_LEADER=03cfeb15b164bb076e2665b761e375f4728041573b89029df29ce114e34ee02ffb \
GENESIS_LEADER_URL=http://45.77.101.95 bollard run

A node follows the leader by default. To stand for leader, send a little bitcoin to the node's address and run bollard enter --fee <sats>. The fee is the entry's weight in the draw.

Make a market

# stake 10 BLRD; one pool backs everything you issue
bollard tx stake --amount 1000000000
# issue 1 BTC of options
bollard tx mint --asset btc:BTC --quantity 100000000
# sell them for on-chain bitcoin; every claim gets its own address from the xpub
bollard tx place-order --market btc:BTC/btc:BTC --side sell --settle 1 --quantity 100000000 \
  --price 100000000 --receive-address xpub... --expiry-height 980000
# or rest them on the ledger; every market is quoted in USDC
bollard tx place-order --market btc:BTC/eth:USDC --side sell --settle 0 --quantity 100000000 \
  --price 9000000000000 --expiry-height 980000

Amounts are in atoms: sats, gwei, 10-6 USDC, rill (10-8 BLRD). Prices are quote atoms per 100,000,000 base atoms. Holders never need BLRD; people use the wallet.

Bollard is early software on mainnet with small amounts. Read the white paper before trading.
