Bollard

A cross-chain exchange where coins come in by being burned, finalized on Bitcoin.

Every account has a keyless burn address on each chain. Send bitcoin to yours and it is gone from Bitcoin and in your balance here, one for one. Balances move instantly and for free, trade against dollars on the book, and leave by being sold to someone coming in. No custodian, no bridge, nothing wrapped: the supply on Bollard is exactly what was burned.

One leader at a time sequences everything in milliseconds. Bitcoin picks the leader: every block runs a fee-weighted lottery over entries written to Bitcoin itself, and each winning entry commits to the log, which is how the log is finalized.

AppA wallet: create a passkey, deposit, send in any currency, withdraw. Pro mode has the book and charts. White paperThe protocol in full: lottery, sequencing, burns, exits. SourceThe node, in Rust. One binary and a Postgres database. APImainnet.bollard.exchange: JSON and server-sent events.

Run a node

cargo install --git https://github.com/masonforest/bollard
bollard keygen
DATABASE_URL=postgres://localhost/bollard BOLLARD_KEY=<secret> \
GENESIS_HEIGHT=971258 GENESIS_LEADER=03cfeb15b164bb076e2665b761e375f4728041573b89029df29ce114e34ee02ffb \
GENESIS_LEADER_URL=http://45.77.101.95 bollard run

A node follows the leader by default. To stand for leader, send a little bitcoin to the node's address and run bollard enter --fee <sats>. The fee is the entry's weight in the draw.

Make a market

bollard burn-address --account <pubkey hex>   # 1BoLLARD… and 0xb0110a4d…: send coins here to bring them in
bollard tx place-order --market btc:BTC/eth:USDC --side sell --settle 0 --quantity 100000000 \
  --price 9000000000000 --expiry-height 980000

Amounts are in atoms: sats, gwei, 10-6 USDC, rill (10-8 BLRD). Prices are quote atoms per 100,000,000 base atoms. Holders never need BLRD; they use the wallet. Making is done from the command line, since a maker must act while it is away from the browser.

Bollard is early software on mainnet with small amounts. Read the white paper before trading.
