    Use it

    cargo install --git https://github.com/masonforest/bollard
bollard keygen
bollard tx --node https://mainnet.bollard.exchange place-order --market btc:BTC/eth:ETH --side sell \
  --quantity 100000 --price 1500000000 --bond 100000000 --receive-address 0xYourEthAddress --expiry-height 980000
bollard tx claim --order <order id> --quantity 100000 --receive-address bc1qYourBitcoinAddress

    Prices are quote atoms per 100,000,000 base atoms. Atoms: sats for BTC, gwei for ETH, 10-6 for USDC, rill for BLRD. Takers never need BLRD; makers bond it. API at mainnet.bollard.exchange: /status · /markets · /book · /entries · /epochs · /log/range
