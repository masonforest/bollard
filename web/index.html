Bollard

A cross-chain order book with real settlement, finalized on Bitcoin.

Makers rest orders backed by a bond. Takers claim them and pay first, on the maker's chain. The maker pays once the taker's payment is in a block, and anyone may deliver in the maker's place and take the bond. The coins move on their own chains; nothing is wrapped and nobody holds custody.

One leader at a time sequences everything in milliseconds. Bitcoin picks the leader: every block runs a fee-weighted lottery over entries written to Bitcoin itself, and each winning entry commits to the log, which is how the log is finalized.

AppSwap in Simple mode, or trade with charts and the book in Pro mode. White paperThe protocol in full: lottery, sequencing, settlement, bonds. SourceThe node, in Rust. One binary and a Postgres database. APImainnet.bollard.exchange: JSON and server-sent events.

Run a node

cargo install --git https://github.com/masonforest/bollard
bollard keygen
DATABASE_URL=postgres://localhost/bollard BOLLARD_KEY=<secret> \
GENESIS_HEIGHT=971258 GENESIS_LEADER=03cfeb15b164bb076e2665b761e375f4728041573b89029df29ce114e34ee02ffb \
GENESIS_LEADER_URL=http://45.77.101.95 bollard run

A node follows the leader by default. To stand for leader, send a little bitcoin to the node's address and run bollard enter --fee <sats>. The fee is the entry's weight in the draw.

Trade

bollard tx place-order --market btc:BTC/eth:ETH --side sell --quantity 100000 \
  --price 3000000000 --bond 100000000 --receive-address 0x... --expiry-height 980000
bollard tx claim --order <id> --quantity 100000 --receive-address bc1q...
bollard tx report --match <id> --leg taker --txid <txid>

Amounts are in atoms: sats, gwei, 10-6 USDC, rill (10-8 BLRD). Prices are quote atoms per 100,000,000 base atoms. Takers never need BLRD.

Bollard is early software on mainnet with small amounts. Read the white paper before trading.
